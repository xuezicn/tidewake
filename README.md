# 汐境回响 · TIDEWAKE

一个**原创**的英雄收集 × 塔防战斗网页游戏。角色、剧情、UI、音效全部为本作原创，不含任何第三方游戏素材。

> 101 位英雄 · 8 章 96 关 · 主动法术 · 连击觉醒 · Roguelite 试炼 · 手动布阵 · 程序化 BGM

---

## 直接开玩

**方式一（最简单）**

双击 `index.html`。Chrome / Edge / Safari 均可，`file://` 直接运行，不需要服务器。

**方式二（推荐，存档更稳 / Safari 网站）**

```bash
cd tidewake
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

**方式三（Safari 一键本地网站）**

双击 `在Safari打开.command`。它会在本机启动 `http://127.0.0.1:8765` 并自动用 Safari 打开；停止服务器可双击 `关闭Safari服务器.command`。

> 这是**只在本机可访问**的本地网站，不会上传到公网。Safari 的 `http://127.0.0.1:8765` 与 `file://` 属于不同的浏览器存储，存档和密码不会自动互相迁移；需要迁移时在旧页面「账户 → 导出」，再到新页面「账户 → 导入存档为新账户」。
>
> 如果通过 `file://` 打开后存档偶尔丢失，用方式二/三即可。存档存在浏览器 localStorage。

## 怎么玩

1. **继续主线** → 选关 → 首通挑战。
2. 战斗里把底部英雄卡**拖到发光格**，或**点一下卡再点格子**。部署消耗潮能。
3. 英雄能量满后，点英雄卡 / 点场上的英雄**放大招**。
4. 开 **2×/3×** 加速；大招可以手动放，也可以在 HUD 里开「自动大招」。
5. 主动法术：Q 霜潮冻结、W 陨潮轰炸、E 回潮群疗；R 释放潮汐觉醒。
6. 波次开始 5 秒后可点「提前召唤」，用风险换潮能和金币；N 快捷键。
7. 空格 / Esc 暂停，可继续、重开或退出。
5. 打不过就回去**升级 / 突破 / 强化装备 / 共鸣升阶**，或者先去**召唤**。
6. 主线不耗体力、失败不扣次数，放心试。

### 新手 5 分钟路线

```
1-1 → 1-2 → 召唤十连（首次必出 SSR）→ 编队 → 一键升级 → 1-4 精英 → 副本 → 签到/任务
```

### 抽卡

- 单抽 120 星砂，十连 1,000（至少 1 个 SR）。
- **首次十连必出 SSR**，60 抽硬保底，46 抽后概率递增。
- UP 池：SSR 有 50% 是当期 UP，歪了下次必中。
- 抽到重复英雄会转化为该英雄的 **「同名共鸣」**：每个共鸣可升 1 阶，最高 5 阶，全属性提升。
- 每日 1 次免费单抽。

### 战斗

- 8×5 网格、多路径出怪、5 种元素克制。
- 战士 / 输出 / 术师 / 医生 / 辅助，五种定位；战士可部署在道路上拦截敌人；所有治疗定位英雄都是医生（共 14 位），优先治疗战士。战士基础生命更高，防御会实际减免受到的伤害，护盾会吸收伤害。
- 击杀、漏怪、放大招、复活、护盾、灼烧、减速、嘲讽、召唤都有。
- 三星条件：通关 / 基地不掉血 / 限时内通关；三星后可扫荡。
- **难度**：新安装默认 **标准**（已有账户保留自己设置）。关卡准备界面或设置里可切换 **休闲 / 标准 / 困难 / 噩梦**；难度会改变敌人生命、攻击、移速、漏怪伤害与基地生命，困难/噩梦的金币奖励更高。
  - 休闲：敌人生命 -15% · 攻击 -20% · 基地 +5
  - 标准：原版节奏
  - 困难：敌人生命 +55% · 攻击 +30% · 基地 -5 · 金币 +25%
  - 噩梦：敌人生命 +140% · 攻击 +65% · 基地 -9 · 金币 +50%

## 账户与存档

- **本地多账户**：右上角账户头像进入账户面板；每个账户独立进度，互不覆盖。
- **新建 / 改名 / 删除**：账户面板内操作；删除前请先导出备份。
- **用户名唯一**：新建、改名、导入新账户时都会校验，不能与现有账户重名；英文大小写、首尾空格视为相同。旧存档中的重名会在读取时自动改为「名字·2」。
- **每账户导出**：账户列表每行的「导出」生成该账户的存档码；可在其他设备导入。
- **导入**：可「导入为新账户」，也可「覆盖当前账户」；覆盖不可恢复，请先备份。
- **开发者账户**：内置「开发者」账户，无限资源（界面显示 ∞）、101 位英雄满级满阶、96 关全三星；账户面板可一键重置。开发者账户不可删除或改名。
- **账户密码**：**创建账户时即可设置密码**，也可之后单独修改 / 清除；每个账户的密码互相独立，启动游戏、切换账户时分别验证。
- **本地锁**：密码用 PBKDF2-SHA256（12 万次迭代）哈希后存于本机，不上传；它不是磁盘加密，能访问浏览器数据或开发者工具的人仍可绕过。忘记密码无法找回。
- **导出码不包含密码**：导入后的账户默认无密码，可重新设置。建议在忘记密码前先导出备份。
- **无云同步**：账户与存档保存在当前浏览器；换设备请用导出码迁移。

## 刻意简化 / 未做

- 立绘是 **SVG 程序化生成的「全息投影」风格**，不是手绘厚涂；后续可替换为正式立绘。
- 剧情是**章节档案**，没有逐关对话演出。
- 无后端：没有好友、公会、在线排行榜、世界 Boss、真实支付。
- BGM 是程序化合成，不是完整编曲；可后续替换为正式音乐。
- 状态效果做了灼烧/减速/嘲讽/护盾/护甲/再生/分裂/冲锋，但没有完整的元素反应系统。

这些不影响单机推图与抽卡闭环。
